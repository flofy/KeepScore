# KeepScore

A modern, mobile-first SPA/PWA inspired by [KeepScore](https://github.com/nolanlawson/KeepScore).

## Status

🚧 Early development.

## Vision

A fast, offline-first score keeper designed for playing tabletop and card games on a phone.

## Goals

- Fast score entry
- Multiple players and games
- Undo/redo and complete score history
- Local-first persistence
- Responsive, mobile-first UI
- Installable PWA
- No account required for core functionality

## Development

The application architecture and implementation will be introduced incrementally.
